

# 🎯 Aim Fruit From Tree Game

A fun Java Swing game where the player controls a **cannon** to shoot fruits from trees.
The game includes levels, scoring, ammo limits, wind effects, and falling fruit animations.

---

## 🚀 Features

* 🌳 Multiple trees with randomly placed fruits.
* 🎯 Cannon with aiming system (controlled by mouse).
* 💨 Dynamic wind effect influencing bullet path.
* 🍎 Different fruit types with varying scores (Apple, Orange, Cherry, Pear).
* 🔫 Limited ammo system to add challenge.
* 🏆 Multiple levels with increasing difficulty.
* 🎮 Smooth animations at 60 FPS.

---

## 🖥️ Controls

* **Mouse Move** → Aim the cannon.
* **Mouse Click** → Shoot bullet.
* **Space** → Reset current level.
* **N** → Next level (after completing).
* **R** → Restart game (after game over).

---
## ⚙️ Requirements

* Java **JDK 8+**
* Any IDE (Eclipse, IntelliJ, VS Code) or simply **javac + java** commands.
---

## ▶️ How to Run

### Using Terminal

```bash
# Compile
javac AimFruitFromTreeGame.java

# Run
java AimFruitFromTreeGame
```

### Using IDE

1. Open project in your IDE.
2. Run `AimFruitFromTreeGame.java` main method.
